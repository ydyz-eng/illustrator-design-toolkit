# 1.3：画布三次点击，自动尺寸标注

## 使用方法

在 Illustrator 的「AI 设计工具箱」中点击「重载插件」，确认右上角为 **1.3**。如果旧实例的内容区空白且重载按钮无响应，请先保存文档，再重启 Illustrator；菜单里隐藏、重新显示面板可能仍保留旧页面。

1. 进入「尺寸标注 → 画布点击」，先设置单位、精度、倍率和标注样式。
2. 点击「开始画布标注」。
3. 在 Illustrator 画布上依次**单击起点、终点、尺寸线放置位置**。空白处也可，不需要选中对象。
4. 第三次点击后自动生成标注，无需返回面板点击生成。

前两个点决定测量长度，支持水平、垂直和任意斜向；第三点决定尺寸线所在侧边及其到测量线的垂直距离。尺寸线始终平行于前两点的连线，标注的是真实直线距离，不是折线路径总长。

取点期间面板显示当前步骤，锁定本次样式设置。使用原生钢笔采集画布坐标，因此请单击，不要拖动手柄、闭合路径或添加第四点；旧宿主如无法自动切换工具，可按提示在 Illustrator 中按 P。

## 恢复与兼容

- 原图层暂时锁定，避免钢笔修改已有图稿；完成或「取消并恢复」后恢复锁定状态、选区和活动图层，并清理确认属于本次取点的辅助线。
- 单击第三点后，请等自动生成完成再开始其他操作。
- 切换到其他文档时暂停生成；切回开始取点的文档即可继续。
- 重开面板会恢复尚未结束的取点会话；请先完成或取消，再保存并关闭文档。
- 生成失败后暂停自动尝试。修正问题后按下方「重试生成标注」，或取消后重新开始；不会因反复检查而重复生成。
- 对取点中添加的额外图稿保留处理，不将其作为辅助线静默删除。
- 原有「标注已选两点」仍保留：用直接选择工具选择两个锚点后点击此按钮。这一方式使用面板中的侧边和偏移参数。

## 实现与验证

新增 `js/dimension-poll.js`：单请求后台检查，第三点就绪时自动完成；取消等前台请求排在已发出的检查之后执行。完成结果按会话缓存，重复回调不会重复生成。

修复 CEP 混合环境中的模块导出，并将 JSX 加载放到顶层，使取点入口和会话跨面板调用保留。

`npm test` 覆盖几何、会话状态、后台检查、错误恢复、取消排队、JSX 加载和原有功能；`npm run check` 检查前端语法。`tests/host-smoke.jsx` 可通过 Illustrator「文件 → 脚本 → 其他脚本」运行，用临时文档检验原生对象行为；结果写入 `tests/host-smoke-result.txt`。脚本构造端点测试与鼠标三次点击的交互验证是两种不同的检查。

2026-09-26 验证结果：前端语法检查通过，Node 测试运行器报告 97 项通过；Illustrator 2023（27.5.0）真实宿主脚本检查 93 项通过，包含两侧第三点定位、自动完成幂等、样式参数、原选区及锚点/手柄状态恢复。完整鼠标交互尚待扩展面板重新加载后的人工确认。
