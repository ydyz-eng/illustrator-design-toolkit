# 1.2：折边样式、斜边与鼠标两点标注

> 当前 1.3 已将鼠标取点升级为三次点击自动生成，请使用 [1.3 操作说明](UPDATE-1.3.md)。以下保留 1.2 历史说明。

## 折边继承原样式

生成折边时复制对应来源路径，再替换折边几何；不再强制变成黑色填充、无描边。

填充/无填充、描边/无描边、颜色、线宽、虚线、端点、连接、透明度等跟随来源路径。渐变、图案、专色和路径外观通过 Illustrator 的原生复制保留。多对象、开放路径、闭合路径以及复合路径各自使用相应的来源路径。

父级群组或图层上单独设置的整体效果不属于路径本身；这类外观与画笔、多重外观的最终呈现需在 Illustrator 中核对。

## 斜边标注

在「尺寸标注 → 斜边标注」中，选择路径并生成，即沿直边标注真实边长，文字随边倾斜并保持可读方向。

- 旋转矩形、多边形和开放折线均可；闭合路径包含首尾相连的边。
- 用直接选择工具选中部分锚点时，仅标注两端均被选中的相邻直边。
- 曲线段跳过，不把曲线的弦长冒充曲线长度。
- 自动侧边对闭合路径朝外；开放路径沿路径方向取左侧。也可手动选择左侧、右侧。
- 剪切群组仅处理剪切轮廓。此模式测量锚点几何，不计描边厚度。

## 任意两点：鼠标点击

1. 选择「尺寸标注 → 任意两点 → 开始鼠标取点」。
2. 在 Illustrator **画板上依次单击起点、终点**，不要拖动手柄或添加第三点。
3. 返回面板，可按「检查端点」核对状态；设置标注侧边、偏移、字号等。
4. 点击「生成尺寸标注」。工具读取两个真实端点的坐标，生成直线距离标注并清理临时取点线。

取点使用原生钢笔工具，当前画板内容仍可见。工具创建单独的临时图层，并暂时锁定其他顶层图层，防止钢笔误改原对象；完成或「取消取点并恢复」后还原原来的锁定状态、选择和活动图层。旧版 Illustrator 若不能自动切换工具，按面板提示在 Illustrator 中按 **P** 即可。

取点期间切换文档不会把标注写入其他文档；请切回原文档完成，或取消取点。重载或关闭后重开面板会恢复当前取点会话，可继续或取消。不要在取点中保存并关闭 Illustrator；先完成或取消以恢复图层。

如果误绘了其他对象、闭合路径或多点曲线，取消时保留这些额外图稿，放在「尺寸取点 · 保留的额外图稿」图层中。只有确认属于本次取点的简单辅助线会自动删除。

也可以不用启动取点：用直接选择工具选择恰好两个锚点（可跨不同路径），或选择一条仅有两个端点的线段，然后在「任意两点」模式直接生成。这里测量的是两个端点的直线距离。

## 验证与加载

执行 `npm test` 检查后端几何、样式继承、回滚、取点生命周期和原有功能；`npm run check` 检查面板脚本语法。浏览器预览可检查新模式和界面，无法代替 Illustrator 中的原生点击。

已扩展 `tests/host-smoke.jsx`，可在 Illustrator「文件 → 脚本 → 其他脚本」运行；只操作临时测试文档，结束后不保存并恢复原活动文档。有未结束的用户取点时会拒绝执行。此前本机 COM 附着不可用，本轮未将自动测试称为实机验证。

更新后关闭并重新打开扩展，再点击「重载插件」。本版新增 `jsx/dimension-pick.jsx`，复制安装时需要保留该文件。

实现依据：Adobe 的 [PathPoint 锚点接口](https://ai-scripting.docsforadobe.dev/jsobjref/PathPoint/)、[钢笔点击操作](https://helpx.adobe.com/illustrator/using/tool-techniques/pen-tool.html)；旧版工具切换兼容参考 [AiCommandPalette 的版本说明](https://github.com/joshbduncan/AiCommandPalette/issues/6)。
