# 1.1 更新与使用说明

## 界面

统一深色面板、工具分组、常用入口和工具搜索。默认面板为 360 × 760；保留 240 px 最小宽度。底部显示执行反馈，尺寸标注的操作按钮常驻内容底部。

记住上次打开的工具和尺寸标注参数。三个样式预设只调整偏移、字号、箭头和线宽；测量范围、单位、倍率与文字设置保持当前值。示意图反映选项，并非实时读取 Illustrator 的选区。

## 尺寸标注

1. 在 Illustrator 中选择图稿，在工具箱中打开「尺寸标注」。
2. 选择逐个对象、整体尺寸、对象间距或当前画板。间距要求两个有效对象，画板模式无需选择。
3. 设置宽高开关、上下左右位置、单位、小数位、偏移和数值倍率。
4. 调整样式后生成。结果位于「尺寸标注 · AI设计工具箱」图层，每次生成一个可编辑分组。

支持 mm、cm、in、pt、px；px 使用 Illustrator 的 72 px/in。按 1:10 缩小绘制的图稿填倍率 10，倍率只换算标签，不改变原图稿。大画布倍率另外自动换算。

几何边界不含描边，可见边界含描边；剪切群组以剪切路径的几何外框为准。旋转对象测量文档坐标轴的外接矩形，并非斜边长度。重叠或相接的间距方向会跳过；两个方向均无正间距时提示错误。

更多选项包括实心/开放箭头、斜线刻度、无端点、线宽、引线留空和超出、前后缀、单位开关、去除末尾零、自定义颜色。小尺寸自动将箭头和文字移到尺寸线外。

「移除上次标注」删除最近一批；「清除全部标注」仅清除本版本写有归属标记的分组，保留旧版标注、同名用户图层以及未标记内容。原图稿修改后需重新生成，标注不自动跟随图稿更新。

## 功能审查与修复

| 工具 / 范围 | 修复或审查结果 |
| --- | --- |
| 全部工具 | 运行前校验有效数值和声明范围；阻止并行执行；新任务开始时隐藏旧结果；修复 JSX 重载常量缺失及失败反馈 |
| 线长和孔洞 | 开放路径只累计线长；曲线轮廓按真实边界近似检查包含关系；区分孔洞和嵌套实心区域；大画布换算；单价修改即时更新总价 |
| 随机填充 | 检查闭合容器、曲线边界与图形对角线；使用全部填充图形，限制生成数量 |
| 加折边 | 校验参数；全选与各方向同步 |
| 圆台 / 螺旋 | 有效数字检查，螺旋限制生成锚点数量 |
| 沿路径分布 | 移除重复选区查询；数量校验；提示警告；保留手动「识别当前选区」入口；生成成功后清理旧结果，失败回滚新内容 |
| 曲线等分 | 整数范围校验；切断模式禁用无关的标记直径；失败保留旧结果，清理时保护当前输入对象 |
| 镜像 | 保留现有几何实现，统一表单校验和面板布局 |
| 文本替换 | 从后向前修改匹配文字范围，避免整框重写破坏未匹配文字的格式；支持换行和选择去重 |
| 批量 AI / DXF | 自动避开同名文件；使用对象复制导出，保留源选择及剪贴板；失败时只关闭自身临时文档 |
| 区域 PNG | 修复不同对象被相同名称/边界信息误判重复的问题 |

孔洞采用闭合轮廓的几何奇偶嵌套估算，不等同于 Illustrator 的填充布尔运算。自交、相交和叠加填色图稿仍需复核。PNG 复杂复合路径中的重叠分离区域仍采用包围框裁切，需检查输出。字体实际度量、混合文字样式、各导出格式及宿主撤销行为需要真实 Illustrator 验证。

## 验证与本地预览

无需安装依赖，使用 Node.js：

```powershell
npm test
npm run check
npm run preview
```

预览地址为 `http://127.0.0.1:8217`，只提供本地界面和交互；实际生成需在 Illustrator 中执行。自动测试使用模拟 Illustrator DOM，覆盖尺寸几何、状态恢复、错误回滚、清理范围、导出防覆盖和文字替换等回归。

本次浏览器检查覆盖全部 12 个面板在 240 px 的横向布局，以及 360 px 尺寸面板、搜索、参数记忆、输入校验、模式与控件联动。尝试附着本机 Illustrator COM 失败，因此未修改现有文档，也未将模拟测试计为实机验证。

可选宿主检查：在 Illustrator「文件 → 脚本 → 其他脚本」选择 `tests/host-smoke.jsx`；脚本创建临时测试文档，仅修改该文档，结束后不保存并恢复原活动文档。也可用支持 COM 附着的 Windows 环境执行：

```powershell
cscript //nologo tests/host-smoke.vbs "$((Resolve-Path tests/host-smoke.jsx).Path)"
```

更新后关闭并重新打开扩展面板，再点击底部「重载插件」。GitHub 调研与许可说明见 [REFERENCES.md](REFERENCES.md)。
